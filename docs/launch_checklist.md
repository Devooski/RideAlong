# RideAlong Launch Checklist

## Launch-day demo readiness
- Open `index.html` in Chrome, Safari, Firefox, Edge, Android Chrome, and iOS Safari.
- Confirm the navigation menu opens on mobile screen widths.
- Test the demo form using both Passenger and Driver roles.
- Select a match and confirm the modal opens with a four-digit match code.
- Confirm logo and icon files open in Canva as SVG imports.

## Investor demo talking points
- RideAlong is a mobile-first web app that matches people by live route fit, not only static city-to-city listings.
- The current version is a front-end MVP for investor demonstration.
- Backend integration can connect the demo flow to authentication, maps, payment, real-time location, and booking records.

## Next build priorities
1. User authentication and verified profiles.
2. Real route matching using Mapbox or Google Maps APIs.
3. Payment intent integration.
4. Driver-passenger messaging.
5. Admin safety dashboard.
